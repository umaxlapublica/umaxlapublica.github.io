# umaxlapublica.github.io
Página web de la coordinadora UMA por la pública

## Estructura

- `*.html` – páginas del sitio (`index`, `argumentos`, `datos`, `newsletter1-5`, ...)
- `11N/`, `Camisetas/`, `paella/`, `recortes/` – páginas con sus propios recursos
- `imagenes/`
  - `logos/` – logos de UMA x la Pública; `logos/colectivos/` – logos de colectivos y sindicatos
  - `fotos/` – fotos de movilizaciones, una subcarpeta por acto (`15M`, `17S`, ...)
  - `carteles/` – carteles
  - `datos/` – gráficos de la sección de datos
  - `newsletters/newsletterN/` – imágenes de cada newsletter
- `documentos/` – PDFs y documentos (manifiesto, LUPA, reivindicaciones, ...)
- `datos/recortes/` – datos y scripts de la encuesta de recortes (`recortes.py` se ejecuta desde esa carpeta)
